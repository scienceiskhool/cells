Optional photos for the microscope slides
=========================================

The sim looks for these files in this folder first. If a file is missing, it tries
the Wikimedia Commons photo, and if that fails it uses a built-in drawing.

  cheek.jpg   - human cheek cells, methylene blue
  onion.jpg   - onion epidermis, iodine
  elodea.jpg  - pondweed (Elodea) leaf, unstained
  blood.jpg   - human blood smear (red and white blood cells)
  root.jpg    - root hair cells (root cross-section)

Tips
- Crop to a rectangle INSIDE the bright circle, so no black edge shows. The sim
  tiles the photo to fill the view.
- Around 1000-1500 px wide is plenty.
- Use photos you are allowed to use (your own, or openly licensed, credited).
